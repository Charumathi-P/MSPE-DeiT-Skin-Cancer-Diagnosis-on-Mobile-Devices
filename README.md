# MSPE-DeiT-Skin-Cancer-Diagnosis-on-Mobile-Devices

MSPE-DeiT is an AI-powered mobile healthcare application designed for preliminary skin cancer risk assessment using multimodal deep learning techniques.  
The system combines skin lesion image analysis with clinical information to generate an AI-assisted risk estimate

Technologies Used
Python
Artificial Intelligence
Machine Learning
Deep Learning
Vision Transformer (MSPE-DeiT)
XGBoost
Artificial Neural Network (ANN)
Flutter
FastAPI
PyTorch
OpenCV

Key Features
Skin lesion image capture and upload.
AI-based image analysis.
Clinical information processing.
Multimodal prediction using MSPE-DeiT, XGBoost and ANN.
Soft-voting ensemble learning.
Mobile-based result visualization.
Assessment history management.

System Architecture
The system consists of:
Flutter Mobile Application – Frontend.
FastAPI – Backend API.
MSPE-DeiT – Image analysis.
XGBoost and ANN – Clinical data analysis.
Soft-Voting Ensemble – Final risk prediction.
